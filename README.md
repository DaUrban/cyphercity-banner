# Cypher City – Banner-Bilder

Bilder und Videos für die Ingame-Banner auf dem Cypher-City-Server.
Alles, was im Ordner [`images/`](images/) liegt, erscheint im Banner-Editor (**F6 → Galerie**) und kann per Klick auf einen Banner gelegt werden.

## Bild hochladen

1. Den Ordner [`images/`](images/) öffnen.
2. Oben rechts auf **Add file → Upload files** klicken.
3. Dateien ins Fenster ziehen und unten auf **Commit changes** klicken.

Nach ein paar Sekunden taucht das Bild im Editor auf (in der Galerie auf **Neu laden** klicken).

Unterordner sind erlaubt, z. B. `images/werbung/` oder `images/events/` – die Galerie zeigt sie gruppiert an.

## Formate

| Art | Formate | Hinweis |
| --- | --- | --- |
| Bilder | `png`, `jpg`, `jpeg`, `webp`, `gif` | GIFs laufen animiert |
| Videos | `webm` | MP4 spielt FiveM je nach Version nicht ab |

Tipps:

- Bilder möglichst im Seitenverhältnis des Banners anlegen (z. B. 16:9 → 1920 × 1080). Im Editor übernimmt **Verhältnis vom Medium** das Format automatisch.
- Große Dateien (über ~10 MB) laden ingame langsam – lieber komprimieren.
- Dateinamen ohne Leerzeichen und Umlaute, z. B. `sommer-event-2026.png`.

## Wichtig

Das Repository ist **öffentlich** – alles hier ist für jeden sichtbar. Keine privaten oder vertraulichen Bilder hochladen.
